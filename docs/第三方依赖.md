# 第三方依赖

项目自己的代码采用 MIT；依赖仍按各自许可证使用。确切版本和来源校验值以 `package-lock.json` 为准，直接和传递运行依赖的原始许可文本保存在根目录 `THIRD_PARTY_NOTICES.txt`。原型内置 fflate 另保留 `docs/prototype/fflate.LICENSE.txt`。

本次检查了锁文件所有条目的许可证元数据和本机实际安装的运行依赖原文。元数据不等于逐行源代码法律审查；复制、分发构建产物或容器时应一并保留适用原始通知。

## 运行与开发依赖

运行依赖的锁文件元数据为 MIT、ISC 等许可；Lucide 的许可原文包含 Feather 衍生部分署名，已原样保留。

Wrangler 开发依赖间接引用 Sharp/libvips 平台可选包，其中存在 LGPL-3.0-or-later 和组合许可证元数据。它们属于开发工具链，不应把整个依赖树描述成“只有 MIT”。源码包不携带这些二进制；如果另行分发相关开发工具或二进制，需要审查并满足这些组件各自的分发要求。正式容器使用 `npm ci --omit=dev` 安装运行依赖，构建工具不复制进最终镜像。
