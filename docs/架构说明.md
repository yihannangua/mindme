# 架构说明

mindme 以单用户空间为数据边界，浏览器先在本地保存内容，再通过可选后端同步。当前不提供多租户账号隔离或公共注册。

## 模块

| 位置                                        | 职责                                                          |
| ------------------------------------------- | ------------------------------------------------------------- |
| `src/domain/`                               | 脑图模型、命令、字段补丁、撤销/历史/回收站和边界校验          |
| `src/layout/`、`src/editor/`                | 树布局、文本测量、SVG 画布、导航、选择及拖拽                  |
| `src/workspace/`                            | 分区工作区、导入和快捷键界面                                  |
| `src/app/`、`src/persistence/`              | 内存快照、编辑草稿、IndexedDB 事务、待同步队列和本机偏好      |
| `src/sync/`                                 | 字段合并、设备序号、时间估计、增量拉取和重试                  |
| `server/`                                   | Node HTTP/静态资源、SQLite WAL、Passkey、WebSocket 和后台清理 |
| `shared/`                                   | SQL 存储适配面、状态差异和完整空间迁移格式                    |
| `workers/auth/`、`workers/api/http.ts`      | Node 与 Worker 复用的认证、Cookie、安全响应头及 HTTP 工具     |
| `workers/index.ts`、`workers/space-object/` | Cloudflare 历史兼容入口                                       |
| `public/sw.js`、`scripts/offline-shell.mjs` | 构建后按哈希缓存应用静态壳，不缓存认证和 API                  |

## 保存与同步

领域命令产生新快照和待同步操作；本地快照与 outbox 通过 IndexedDB 事务持久化。输入草稿独立保存，失败时保留可导出的内容。服务端按字段版本合并，记录删除信息和操作去重结果，并向在线端发送 WebSocket 通知。断网重连保留重试和身份检查，不直接清空队列。

视角、当前选择、分区布局和撤销栈属于本地交互状态，不跨设备同步。历史新增以 `history-add` 传播，兼容旧客户端完整历史字段；大差异可能回退到完整空间读取。

## 服务端

Node 后端使用固定 `PUBLIC_ORIGIN` 校验请求来源，生产要求 HTTPS。Passkey 认证签发访问/刷新 Cookie；刷新令牌仅存哈希并逐次轮换，重放撤销相关刷新链。后台任务处理到期历史、回收站和会话，数据库保存在独立持久卷。

布局、导入和完整空间读取的资源开销受空间大小影响；没有实现后台布局 Worker或按需加载全部历史。部署需要结合实际使用量验证内存和备份恢复。
