# 测试说明

## 验证范围

| 命令                     | 覆盖                                                    |
| ------------------------ | ------------------------------------------------------- |
| `npm run check`          | 前端/Node/Worker 类型、单元/集成测试、源码格式          |
| `npm run test:prototype` | 独立内存草图的导入与快捷键行为                          |
| `npm run build`          | 前端类型、Vite 打包和离线静态壳                         |
| `npm run build:server`   | Node 类型和两个服务端入口构建                           |
| `npm run test:e2e:ci`    | Chromium 与 WebKit 的画布、编辑、导入、工作区和性能样本 |
| `npm run test:node`      | 本地 Node/SQLite 双设备、认证/Passkey 和恢复流程        |
| `npm run test:cloud`     | 历史兼容 Worker 本地集成，非首选云端部署验收            |

```bash
npm ci
npx playwright install chromium webkit
npm run check
npm run test:prototype
npm run build
npm run build:server
npm run test:e2e:ci
npm run test:node
```

Linux CI 使用 `npx playwright install --with-deps chromium webkit` 安装浏览器及系统依赖。工作流只读仓库内容，不使用生产凭据，也不自动部署。

`npm run test:e2e` 默认额外包含本机 Google Chrome；未安装时使用 `test:e2e:ci`。WebKit 不支持 Chromium CDP 的原生输入组合事件测试，相关项目会跳过，其余输入场景仍验证。

## 隔离与结果

测试只使用生成的演示脑图和临时数据库。`test-results/`、`.wrangler/` 和 Playwright 报告均不入 Git。不要把测试数据库参数指向自己真实数据。

浏览器性能用例测量本机、合成数据与自动化引擎，不代表公网时延、物理屏幕帧率或所有设备表现。首次设置通过虚拟认证器验证，不代替真实设备 Passkey 人工验收。端口 4173、8792、8793 需空闲；历史 Worker 测试使用 8791。

最新公开快照的本次验证结果见[发布前检查](发布前检查.md)。GitHub Actions 的远程执行结果需要仓库正式创建并推送后另行核验。
