# 交互草图第三方依赖

草图只用于在内存中演示交互，不与正式应用共享数据和运行时。

- `fflate.min.js` 为 `fflate@0.8.3` 的 UMD 副本，用于浏览器解压 XMind 8；原始 MIT 许可证在 `fflate.LICENSE.txt`，不得删除或翻译法律原文。
- `@xmldom/xmldom` 用于 Node 草图导入测试；正式应用也使用该包处理 XML，两个路径的运行时相互独立。
- 正式依赖的确切版本以根目录 `package-lock.json` 为准，第三方通知见 [第三方依赖](../第三方依赖.md)。

更新草图副本时同步许可证和锁文件，并运行 `npm run test:prototype`。
